Opening the App

Open any browser and go to:

https://gilbar2.github.io/know-graph/

The knowledge graph loads immediately — no password or login is needed for the public view.

🖥 Screenshot: Full app on first load — dark canvas, glowing nodes, header with logo and search
02

The Graph Canvas

The main view is a live, physics-driven graph. Each circle is a node (an entity in the archive). Lines between nodes are edges (relationships).

ActionResult
Click a nodeOpens the info panel for that node
Drag a nodeRepositions it; surrounding nodes adjust via physics
Drag the backgroundPans the entire canvas
Scroll wheel / pinchZooms in or out
Click empty spaceCloses the open info panel

Node size reflects relative importance. Node color reflects its category. A thumbnail image appears inside the circle if one has been assigned.

🔵 Screenshot: Graph canvas with several nodes; one hovered, glowing, with neighbors highlighted
03

Searching for Nodes

The search bar is at the top-right of the screen. Type any part of a node's Hebrew name to filter the graph in real time.

  1. Click the search bar (or start typing)
  2. Matching nodes brighten; non-matching nodes fade
  3. Clear the search field to restore all nodes
🔍 Screenshot: Search bar with Hebrew text entered — matching nodes highlighted, others dimmed
04

Node Info Panel

Click any node to open its info panel on the right side of the screen. The panel contains:

  1. Node title — large heading at the top
  2. Category badge — color-coded pill showing the category
  3. Thumbnail image — if assigned, shown above the description
  4. Description — freeform Hebrew text about the node
  5. Google Drive carousel — embedded file browser for the node's linked Drive folder (documents, images, videos)
  6. Connected nodes — clickable list of directly linked nodes

Click anywhere on the empty canvas to close the panel.

📋 Screenshot: Info panel open — thumbnail, description text, and Drive carousel visible
📁 Screenshot: Drive carousel grid view showing folder contents inside the panel
05

Category Legend

The legend lives in the bottom-left corner. It lists the 8 categories, each with its color and icon.

  1. Click a category to filter — only nodes in that category stay fully visible
  2. Click again (or click another category) to clear the filter
🏷 Screenshot: Legend panel, bottom-left — one category selected, others dimmed on the canvas

Admin Panel — Logging In

The admin panel lets authorized users edit node content, manage connections, and add images.

  1. Click the ⚙ gear icon in the top-right corner of the header
  2. Enter the admin password in the prompt that appears
  3. The admin panel slides in from the right

Editing Node Labels & Descriptions

Every node appears as a row in the admin panel's node list. To edit one:

  1. Scroll to the node (or use the list)
  2. Click + ערוך תיאור to expand the editing area
  3. Update the label (name) field
  4. Update the description text area
  5. Click שמור שינויים to save
Tip: Each node row also has a checkbox — use it to select nodes for connect/disconnect operations (see sections 12–13).
✏️ Screenshot: A node row expanded showing label field and description textarea

Adding a Thumbnail Image (Crop Tool)

Each node can have a custom thumbnail — it appears inside the node circle and at the top of the info panel.

  1. In the admin node list, click + הוסף תמונה on the node you want
  2. Choose an image file from your device
  3. The crop tool opens showing your image with a square selection box

Using the crop tool:

ActionHow
Move the crop boxClick and drag inside the box
Resize the crop boxDrag any of the 4 corner handles
Aspect ratioAlways locked to 1:1 (square)
  1. Position and resize the box to frame the part you want
  2. Click ✓ אשר חיתוך to save (output: 180×180 px JPEG)
✂️ Screenshot: Crop tool open — image displayed with square selection box and 4 corner handles
🖼 Screenshot: Node on the graph with custom thumbnail visible inside the circle
To replace a thumbnail: click + הוסף תמונה again and repeat the process.
11

Auto Thumbnail Generation

The 🖼 auto thumbnail button (purple, in the admin footer) instantly generates a designed thumbnail for every node that doesn't already have one — no image upload required.

  1. Scroll to the bottom of the admin panel
  2. Click the purple 🖼 auto thumbnail button
  3. Thumbnails are generated for all nodes without one, using:
ElementSource
Background gradientCategory color
Central iconCategory emoji
Text labelNode's Hebrew name
Color bar at bottomCategory name + color
Note: Auto thumbnail skips nodes that already have a manually uploaded image.
🎛 Screenshot: Admin footer showing the blue "Connect", orange "Disconnect", and purple "Auto thumbnail" buttons
✨ Screenshot: Graph after auto thumbnail — nodes showing generated thumbnails with icons and labels
12

Connecting Nodes

To add a new edge (connection line) between two nodes:

  1. In the admin node list, check the checkbox next to the first node
  2. Check the checkbox next to the second node
  3. Click the 🔗 חיבור צמתים button in the admin footer
  4. A new edge appears on the graph between the two nodes
  5. Checkboxes are cleared automatically
☑️ Screenshot: Two checkboxes checked in the admin node list
🔗 Screenshot: New connection line visible between the two nodes on the graph
13

Disconnecting Nodes

To remove an existing edge between two nodes:

  1. Check the checkbox next to both nodes
  2. Click the ✂️ ניתוק צמתים button in the admin footer
  3. If an edge exists between them, it is removed from the graph
Note: If no edge exists between the two selected nodes, nothing happens.
✂️ Screenshot: Orange "Disconnect" button in the admin footer
14

Saving Changes

Admin changes (labels, descriptions, thumbnails, edges) are saved to the browser's localStorage and persist across page reloads in the same browser.

  1. Click the green שמור שינויים button at the bottom of the admin panel
  2. The button shows ✓ נשמר! briefly to confirm
💾 Screenshot: Green "Save changes" button at bottom of admin panel
Important: Changes are saved locally in your browser only. Opening the app in a different browser or device will show the default data. To publish changes for all users, the source file must be updated and redeployed.
